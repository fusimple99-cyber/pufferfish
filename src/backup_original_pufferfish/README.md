# 河豚 · 本地交互网页

直接使用提供的 `河豚.blend` 导出的原网格，白色背景，无可见地面。按住河豚约 2 秒等比例放大到 1.35 倍，松开约 1.2 秒恢复。支持鼠标、手机触摸和键盘空格 / Enter。

## 打开网页

macOS 可双击 `启动河豚.command`，保持弹出的终端窗口开启，然后访问：

**http://localhost:8765/**

也可以在这个文件夹中运行：

```sh
python3 server.py
```

需要 Python 3 和支持 WebGL 2 的现代浏览器。网页使用 JavaScript 模块及 GLB 资源，请通过上述地址打开，不要双击 `dist/index.html` 使用 `file://`。首次打开会用几秒钟准备玻璃画面，显示进度后即可操作。整个运行过程不请求外部网络，不需要安装 Node、npm 或 Blender。

同一 Wi-Fi 下用手机测试：

```sh
python3 server.py --lan
```

然后在手机浏览器打开 `http://电脑的局域网IP:8765/`。默认启动仅允许本机访问；`--lan` 才允许同一局域网访问。终端按 Ctrl+C 结束服务。端口冲突时可加 `--port 8766`。

## 造型和材质

- 8 个原始部件全部保留：身体、嘴、左右眼、左右鳍、背鳍、尾鳍。导出保留身体 Solidify 内壁和 Subdivision 结果，共 144,672 个三角面。
- 通过数值对比检查了每个部件导出前后的世界坐标顶点、三角面数量。最大顶点位置误差约 0.0000082 个 Blender 单位，为导出数值精度范围；未重建、减面或改变部件位置。原文件 SHA-256 校验保持一致。
- 原程序纹理经 Blender 烘焙为本地贴图，内嵌在 GLB 中；独立 PNG 也随项目保留。
- 使用原始相机方向及灯光位置。仅屏幕尺寸变化时调整取景范围；长按过程中相机完全固定。
- 所有部件围绕模型底部附近的同一支点等比例缩放。没有单独移动眼睛，没有身体形变。

## 为什么更换渲染方式

第一版的屏幕空间透射不能正确显示玻璃内的眼睛和重叠透明部件。现在使用 three-mesh-bvh 对实际导出三角面追踪多次折射，读取原外壳与内壁，从原始位置显示眼睛。可见地面和阴影已移除，纯白背景与用于高光的不可见摄影棚灯光分开处理。

为了让长按流畅，加载时在浏览器中按 49 个等比例尺寸预计算玻璃画面，交互时插值显示相邻缓存。缓存来自本地原始三维网格，原模型仍用于交互命中判断。没有使用效果图切片或替代角色图片。缓存存在显存中，约 90 MB；调整窗口大小会重新准备画面。很旧的移动设备可能需要更长准备时间。

这是适合固定视角、只做整体缩放的优化方案。插值期间轮廓和高光存在轻微过渡；不适用于自由旋转模型或动态改变灯光。

### 与 Blender 渲染仍有差异

网页实现并非 Cycles：环境光、粗糙度、高光与眼睛着色使用轻量近似；没有完整的间接光、次表面散射和无限次反射。色调和折射细节不能承诺与原效果图逐像素一致。空心结构和部件遮挡来自真实网格，材质外观仍属于网页适配。白底、去地面也会改变与原效果图相比的视觉感受。

## 项目内容

- `dist/`：可直接由静态服务器运行的完整网页。
- `dist/assets/pufferfish.glb`：原模型导出及内嵌贴图。
- `dist/glass-renderer.js`：三角面折射、摄影棚高光与缩放缓存。
- `dist/interaction.js`：连续缩放和输入取消处理。
- `source/河豚.blend`：提供的源文件副本。
- `scripts/`：Blender 检查、烘焙导出、几何核对和浏览器验证脚本。
- `verification/`：检查报告、桌面与移动端模拟截图。

修改放大范围时，需要同步修改 `app.js`、`interaction.js` 和 `glass-renderer.js` 中的 1.35 / .35。修改玻璃材质可调整 `glass-renderer.js` 中的光学与环境参数。

## 验证范围

已用本机 Chrome 的桌面视口与手机触摸模拟验证：长按、松开、中途再次按下、移出画布、窗口失焦、触摸取消、最大尺寸不裁切、横屏重新适配，以及无外部资源请求。截图和机器可读结果见 `verification/browser-results.json`。移动端验证为浏览器模拟，未在实体手机上实测。

几何核对结果见 `verification/geometry-results.json`；原场景记录见 `verification/source-inspection.json`。

## 参考与依赖

参考了 [Ohayo Studio](https://github.com/zhangluweivivi/ohayo-) 的本地资源组织和玻璃表现思路。该仓库通过调整眼睛位置解决透明遮挡；本项目没有采用这一做法，也没有复制它的角色、眼睛或形变逻辑。

随项目本地附带 Three.js 0.180.0 和 three-mesh-bvh 0.9.2，许可证分别位于 `dist/vendor/THREE-LICENSE` 和 `dist/vendor/BVH-LICENSE`。材质参数与透射语义参考 [Three.js MeshPhysicalMaterial 文档](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)。
